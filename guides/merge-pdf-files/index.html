How to merge PDF files into one

By Anand Kumar · Updated 24 October 2026

Free, private, and nothing is uploaded.

Open Merge PDF

Many applications ask for all your documents in a single PDF: certificates, marksheets, ID proof and so on. Here's how to combine them in the right order.

Steps

  1. Open the Merge PDF tool.
  2. Add all the PDF files. You can select several at once.
  3. Put them in order. Drag the rows, or use the up and down arrows on a phone. The first file in the list becomes the first pages of the new PDF.
  4. Type a clear file name, for example anand-kumar-certificates.
  5. Tap Merge PDFs, then Save.

A good order for applications

  1. Application form or cover letter
  2. ID proof
  3. Marksheets and certificates, oldest first (10th, 12th, graduation, post-graduation)
  4. Experience letters and other documents

Always follow the order the application asks for, if it gives one.

Common problems

Some of my documents are photos, not PDFs

Convert the photos first with Image to PDF, then merge. Our guide on turning phone photos into a clean PDF explains how.

The merged PDF is too large to upload

Run it through Compress PDF. See how to reduce PDF size.

"Password-protected" message

Some PDFs, such as e-statements or downloaded certificates, are locked. Open the file with its password in a PDF reader, save or print it as a new PDF without the password, then merge.

Frequently asked questions

Is there a limit on how many PDFs I can merge?

No fixed limit. Each file can be up to 50 MB. Very large merges depend on your device's memory.

Are my documents uploaded?

No. Merging happens in your browser and your documents stay on your device.
